# KOL Campaign Performance Analysis
## Overview
This project focuses on analyzing and visualizing influencer (KOL) marketing campaign performance using Looker Studio. The dashboard was developed as part of an internship project in the influencer reporting and analytics unit of a digital media agency.

The analysis uses campaign data to monitor KOL performance and provide an overview of key campaign metrics across different KOLs and product categories.

## Objectives
- Monitor campaign performance across multiple KOLs and product categories.
- Identify high-performing KOLs based on campaign performance metrics.
- Provide an interactive dashboard for campaign monitoring and reporting.
- Support the evaluation of campaign performance through data visualization.

## Dataset
The dataset contains campaign performance data collected from influencer marketing activities.
The main metrics included in the dataset are:
- Views
- Likes
- Comments
- Shares
- Engagement
- Engagement Rate (ER)
- KOL information
- Product and campaign information
The dataset is provided in CSV format in the `data/` folder.

## Dashboard
The campaign performance dashboard was developed using Looker Studio and provides interactive visualizations of the campaign data.
Key information presented in the dashboard includes:
- Campaign performance overview
- KOL performance
- Views and engagement metrics
- Performance across product categories
- Engagement Rate (ER)
