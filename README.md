# Analysis KOL Campaign Performance
This project visualizes the performance of influencer (KOL) marketing campaigns using Looker Studio. The dashboard provides interactive insights into key performance metrics such as views, engagement, likes, comments, shared, dll. It was developed as part of my internship project in the influencer reporting &amp; analytics unit of a media agency.


- To monitor campaign effectiveness across multiple KOLs and product categories.
- To identify top-performing KOLs based on reach (eyeball) and engagement rate.
- To assist the marketing team in making data-driven decisions for future campaign planning.
